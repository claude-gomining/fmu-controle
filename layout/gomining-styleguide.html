Como Usar

Importe o arquivo de tokens CSS e use as variáveis em qualquer projeto web para manter a identidade visual da Gomining.

1. Importar os tokens

/* No HTML */ <link rel="stylesheet" href="gomining-tokens.css"> /* Ou no CSS */ @import './gomining-tokens.css'; /* Ou no JavaScript */ import './gomining-tokens.css';

2. Usar variáveis no CSS

.meu-botao { background: var(--color-primary-500); color: var(--color-neutral-0); border-radius: var(--radius-full); font-family: var(--font-heading); padding: var(--space-3) var(--space-6); box-shadow: var(--shadow-primary); }

3. Fontes (Google Fonts)

<link rel="preconnect" href="https://fonts.googleapis.com"> <link href="https://fonts.googleapis.com/css2? family=Poppins:wght@500;600;700;800 &family=Inter:wght@400;500;600 &display=swap" rel="stylesheet">

4. Modo escuro

/* Ative no elemento raiz */ document.documentElement .setAttribute('data-theme', 'dark'); /* Ou via HTML */ <html data-theme="dark">

Regras de uso da marca

✅
UseLaranja (#FF7A00) como cor de CTA e destaque principal.
✅
UseAzul escuro (#0D1B3E) para seções hero e backgrounds institucionais.
❌
EviteUsar o laranja como cor de background em grandes áreas.
❌
EviteMisturar fontes fora do sistema (não use Arial ou Times New Roman).
⚠️
AtençãoContraste mínimo WCAG AA: 4.5:1 para texto normal.
⚠️
AtençãoBotões laranja sobre fundo branco: use sempre o shadow-primary.
